**Cloud-Native Agent Platform | AWS | AI Architecture**

A modular platform for recruiting intelligence agents,
designed around standardized contracts and asynchronous
work processing.

Key technologies:
- AWS Lambda, API Gateway, SQS, DynamoDB
- Amazon Cognito, IAM, S3, CloudWatch
- Terraform and Infrastructure as Code
- Agent Registry, Discovery, Eligibility and Routing
- Tenant Isolation and Event-Driven Architecture

Status: Active development with verified platform components.
